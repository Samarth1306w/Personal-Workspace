# Commercial Speed & Engineering Directives
1. Never propose hypothetical solutions when a working prototype can be built in under 5 minutes.
2. All web pages must achieve 95+ PageSpeed scores, zero CLS, and sub-2-second load times.
3. Every client proposal must include either a working demo link, screenshot, or sample data output.
4. If a terminal command or compilation fails, immediately inspect stderr, isolate the line, and self-heal automatically.
